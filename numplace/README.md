# numplace～ナンプレ～

ナンバープレース（ナンプレ）。問題は毎回、答えが必ず1つになるように自動で作る。

URL: `https://<ユーザー名>.github.io/Lapis/numplace/`

## むずかしさ
| レベル | 最初に見える数字 | 内容 |
|---|---|---|
| やさしい | 42 | 「その場所に入る数字が1つ」「その数字が入る場所が1つ」だけで解ける |
| ふつう | 34 | 同上（数字が少ない） |
| むずかしい | 29 | 上のひらめきだけでは解けない手を含む |
| ぎりぎり | 24 | 数字がとても少ない |

## 操作
- マスをタップ → 下の数字ボタンで入力（同じ数字をもう一度押すと消える）
- メモ ON で、小さい数字のメモを入れる
- けす / もどす（何手でも）/ ヒント（選んだマスの答えを入れる。選んでいないときは、まちがいか空きマスを探す）
- 設定: まちがいをすぐ赤く教える / 数字を入れたらメモを自動で消す
- 途中で閉じても「つづきから」で再開できる。ベスト時間はレベルごとに保存

## 調整用定数
`index.html` 冒頭の `const CONFIG = {...}`（レベルごとの数字の数、音量、BGMのテンポ）。
