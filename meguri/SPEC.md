# めぐり ～十年の騎士団～（仮）仕様書 v0.1

対象: 中学生・高校生。UIは漢字を使う。読み物の文章は絵本のナレーション調。
形式: 単一HTML（`index.html`）＋データ（`data.js`）。iPhone/iPadのホーム画面アプリ。サーバーなし。記録は端末内。
着想: 「前・中・後列に配置して、陣形を回しながら戦う」「仲間が年を取り、引退し、次の世代へつなぐ」というゲームの考え方。
**名前・キャラ・世界・絵・文章・音はすべてオリジナル。既存作品の固有要素は使わない。**

## 1. ゲームの流れ
- 時間は **10年 = 40季節**（春夏秋冬×10）。1季節に1回、「遠征」に出る。
- 季節の流れ: ①帰還（出来事・入団希望者）→ ②編成 → ③遠征（戦闘1〜3回）→ ④結果（成長・引退・予言）。
- 目標: 10年目の冬に来る「大災厄」を退ける。途中に予言（3年目・6年目）があり、それぞれ強い敵が現れる。
- 全体の目安: 1季節 3〜5分、通しで約2〜3時間。途中保存（自動）。

## 2. 戦闘（ローテーションバトル）
- 盤面は **横4×縦3**。味方は最大7人を置く。行は「前列／中列／後列」。
- 敵は最大4体。各敵は、味方の同じ「縦の列」を狙う。敵の次の行動（攻撃・強攻撃・全体・回復）は、前もって表示する。
- 1ラウンド: ①プレイヤーが **「そのまま」か「回す」** を選ぶ → ②各自の行動 → ③敵の行動。
  - 「回す」: 4つの縦列それぞれで、前→後、中→前、後→中 に移る。
- **職業ごとに、行ごとの効果が違う。** 前列は「攻撃」、中列は「補助」、後列は「回復・待機」が基本。
- 勝利: 敵を全滅。敗北（撤退）: 味方の前に出ているすべてが倒れる、または12ラウンド経過。敗北しても仲間は失わない（その季節の経験が減るだけ）。
- とどめを刺した仲間に経験値が多く入る（新人に刺させる、という判断ができる）。

### 職業（8種、数値は初期案。`data.js` で調整）
| 職業 | 前列 | 中列 | 後列 |
|---|---|---|---|
| 剣士 | 強い単体攻撃 | 同列の前列の攻撃+20% | 自分を少し回復 |
| 盾兵 | 弱い攻撃・同列をかばう | 同列の前列の防御+25% | 自分を回復 |
| 弓兵 | 単体攻撃 | 同列の前列の攻撃のあとに追撃 | 敵1体にランダム射撃 |
| 魔法使い | 敵全体に小ダメージ | 敵全体に極小ダメージ | 次の前列の攻撃+10%（全体） |
| 僧侶 | 弱い攻撃＋自分回復 | 同列の前列の被ダメージ軽減 | 味方全体を回復 |
| 軍師 | 弱い攻撃 | 前列全員の攻撃+10% | 獲得経験値+ |
| 斥候 | 先制攻撃 | 同列の前列が30%で回避 | 戦利品（装備の経験）+ |
| 吟遊詩人 | 弱い攻撃 | 全員の防御+5% | 全員を少し回復 |

## 3. 仲間・時間・世代
- 能力: 最大HP・攻撃・防御。年齢と職業で変わり、遠征で経験値を得て成長（レベル）。
- **年齢**: 年が変わる（冬の次の春）たびに全員 +1歳。能力は年齢で変わる（若い: 伸びる、20代前半〜後半: ピーク、30代: 衰える）。
- **引退**: 34〜38歳でランダムに引退（引退前に予告を出す）。引退した仲間は「年代記」に名前と功績が残る。装備は次の世代に引き継ぐ。
- **入団希望者**: 毎季節3人が現れ、1人を選べる（職業・年齢・得意な能力・性格がランダム）。団員の上限は12人（出撃は7人）。
- **装備**: 1人1つ。装備を持った仲間が戦うと、装備も経験を積んでランクアップ（ランク1〜5）。引退時に装備は倉庫に戻り、別の仲間に渡せる。
- 友情・恋愛・結婚・子どもは **第2弾（v2）**。v1では入れない。

## 4. 世界・物語（中高生向け）
- 舞台: 小さな王国の「見習い騎士団」。ナレーションは絵本調（「むかしむかし」ではなく、静かで少し切ない語り）。
- 予言: 十年後の冬、「大いなる影」が来る。途中の予言は、季節の初めに表示。
- エンディング: 10年目冬の戦闘の結果と、年代記（歴代の団員、引退年、最後に装備していた物、通算の勝利数）。

## 5. 画面
タイトル／季節の帰還／編成（4×3の盤面にドラッグではなく「タップで選んで置く」）／戦闘／結果／入団希望者／団員一覧／年代記／設定。
操作はすべて片手タップ。小さな文字は避ける（本文15px以上）。

## 6. 見た目・音
- 絵本風: 紙の質感の背景、あたたかい色、キャラはSVGで職業と色の組み合わせから描く（画像素材なし）。
- 音: 静かなピアノ中心のBGMと小さな効果音（オン／オフあり）。iPhoneの消音スイッチの動作はそのまま。

## 7. 作る範囲
### v1（最初の版）
戦闘（回転・職業8種・敵10種・ボス3体）／40季節／年齢と引退／入団希望者／装備の継承（ランク）／年代記／自動セーブ／タイトルと設定。
### v2（その次）
人間関係（友情・結婚・子ども）／世代交代の物語／難易度設定／追加職業・追加敵。

## 8. 検証方法
- 戦闘を自動で何千回も回すシミュレーターで、勝率・平均ラウンド数・職業ごとの強さを確認して数値を調整する。
- 画面は、iPhone表示のブラウザ自動テストで、1年分を通して遊び切れること、セーブ・ロードが働くことを確認する。
- 面白さの調整（手触り、難しさ）は、実機で遊んでもらって、数字を直す。
