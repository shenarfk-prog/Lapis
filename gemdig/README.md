# gemdig～ジェムディグ～

石の下をほっていく、ばくだんよけパズル。数字は「まわりの8マスにあるばくだんの数」。すべての安全なマスをほればクリア（宝石が現れる）。

URL: `https://<ユーザー名>.github.io/Lapis/gemdig/`

## 操作
- 下のボタンで **ほる / はた** を切り替える（長押しは使わない）
- マスをタップ → ほる / 旗を立てる（旗をもう一度タップで外す）
- ひらいた数字をタップ → まわりの旗の数が数字と同じなら、のこりをまとめてほる（設定でOFFにできる）
- 指を離したときに実行する。タップした場所と離した場所がちがうマスなら、何も起きない（エアロバイクの振動対策）
- 最初にほった場所と、そのまわりには、ばくだんがない
- 途中で閉じても「つづきから」で再開できる。ベスト時間はレベルごとに保存

## むずかしさ

## 調整用定数
