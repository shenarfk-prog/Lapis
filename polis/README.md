# polis academy ～公共・政経～

政治・経済（公共）の用語を覚えるためのドリル。高校生向け・個人学習用。

URL: `https://<ユーザー名>.github.io/Lapis/polis/`

## 内容（データ v0.2・下書き）
- 用語 172語（9分野）、正誤問題 164問、対比カード 12セット（94の説明）、条文の穴埋め 41条文（空欄65）、年表 17本、論述テーマ 12
- **説明文は、すべて新しく書いたものです。教科書や問題集の文章は使っていません。**
- **内容の誤りが混じっている可能性があります。必ず先生が確認してください。**

## 出題の種類
| 種類 | 内容 |
|---|---|
| 説明 → 用語 | 説明文を読んで、4択から用語を選ぶ |
| 用語 → 説明 | 用語を見て、4択から正しい説明を選ぶ |
| 暗記カード | 用語を見て思い出し、答えを確認して「覚えた／まだ」を自己採点 |
| 正誤判定 | 文を読んで ○ か × を選ぶ |

- 答えたあとに「考察のポイント」（一部の用語）と、自分の言葉で書くメモ欄が出ます。メモは、あとで「きろく」や結果に表示されます。
- まちがえた用語ほど、あとでよく出ます（習熟度 0〜4）。「覚えた」は習熟度3以上。
- 分野・出題（ぜんぶ／苦手／未学習）・問題数をしぼりこめます。
- 結果は「コピー」して、ノートなどに貼れます。記録は、この端末のブラウザにだけ保存されます。

## 機能
- **今日の復習**: 習熟度から「今日復習する用語」（期限の用語 最大20語）と、新しい用語5語を自動で選ぶ。習熟度ごとに、次の復習は 0日・1日・3日・7日・14日後。「連続学習○日」も表示
- **用語集**: 全用語をキーワード検索（用語・説明・考察・自分のメモが対象）。★で「後で見直す」用語を登録でき、★だけの出題もできる
- **対比カード**: 紛らわしい用語を表で比べる（12セット）。「対比クイズ」では、説明文を見て「どちらの用語の説明か」を答える
- **データ確認（先生用）**: 用語・正誤問題・対比カードを、1つずつ確認できる

## データの確認と修正（先生用）
1. タイトル画面の **「✎ データ確認」** を開く
2. 1つずつ **○確認済み / ✎要修正** を付け、直し方をコメントに書く（分野ごとに「全て確認済み」にもできる）
3. **「要修正・コメントをコピー」** で、まとめて送れる
4. 直接直す場合は、`terms.js` を編集する
   - `t` = 用語、`d` = 説明文、`n` = 考察のポイント（なくてもよい）、`c` = 分野
   - 説明文の中に、用語そのものを書かないでください（「説明→用語」の問題で、答えが見えてしまうため）
   - 正誤問題は `s` = 文、`a` = true/false、`e` = 解説
   - 対比カードは `cmps`: `title` = 題名、`cols` = 比べる用語、`rows` = [観点, 1列目の説明, 2列目の説明]、`n` = 考察
   - 用語を書き換えると、その用語の記録（覚えた状況）は、リセットされます

確認済みの状態は、この端末のブラウザにだけ保存されます（`terms.js` を直しても消えません）。

## 調整用定数
`index.html` 冒頭の `const CONFIG = {...}`（問題数の選択肢、出やすさの重み、「覚えた」の基準、復習の間隔 `INTERVAL_DAYS`、今日の復習の数 `DAILY_MAX` / `DAILY_NEW`、音量）。
- **論述メモ**: 12テーマ。主張・理由・具体例・反論の4欄に書き、自動保存。コピーして提出できる
- **学習記録**: 用語・正誤・対比のすべてを集計。種類別／分野別の習熟、直近14日の解答数グラフ、苦手一覧。ホーム画面アプリとSafariでは記録が別なので注意
- **結果コード／結果集計（先生用）**: 名前を入れて「結果コード」をコピーして先生に送る。先生は「結果集計」に貼り付けると、生徒別・分野別・つまずき項目を一覧できる
- **バックアップ**: 学習記録をコードにしてコピー、別の端末や別のブラウザで復元できる
- 音（BGM・効果音）はありません
- **条文の穴埋め**: 日本国憲法の条文19か所（空欄37）を4択で埋める。条文は公布時の表記
- **年表の並べ替え**: 7つの年表から5つの出来事を選び、古い順にタップして並べる（答え合わせで年も表示）
- **ペア対戦**: 1台を2人で交代しながら4択に答えて得点を競う（名前を入力。学習記録には残さない）
- **問題の追加・取り込み**: 用語と正誤問題を自分で追加（1問ずつ／1行1問でまとめて）。「共有コード」で友だち・先生と交換できる。追加した問題は分野「その他・追加問題」に入る
- **タイムアタック（ON/OFF）**: ONにすると制限時間つきの得点制（基本100点＋速さボーナス最大100点＋コンボボーナス最大100点）。モードごとの自己ベストを記録。暗記カード・ペア対戦は対象外
