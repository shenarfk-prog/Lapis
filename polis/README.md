# polis～政経ドリル～

政治・経済（公共）の用語を覚えるためのドリル。高校生向け・個人学習用。

URL: `https://<ユーザー名>.github.io/Lapis/polis/`

## 内容（データ v0.1・下書き）
- 用語 172語（9分野）、正誤問題 40問
- **説明文は、すべて新しく書いたものです。教科書や問題集の文章は使っていません。**
- **内容の誤りが混じっている可能性があります。必ず先生が確認してください。**

## 出題の種類
| 種類 | 内容 |
|---|---|
| 説明 → 用語 | 説明文を読んで、4択から用語を選ぶ |
| 用語 → 説明 | 用語を見て、4択から正しい説明を選ぶ |
| 暗記カード | 用語を見て思い出し、答えを確認して「覚えた／まだ」を自己採点 |
| 正誤判定 | 文を読んで ○ か × を選ぶ |

- 答えたあとに「考察のポイント」（一部の用語）と、自分の言葉で書くメモ欄が出ます。メモは、あとで「きろく」や結果に表示されます。
- まちがえた用語ほど、あとでよく出ます（習熟度 0〜4）。「覚えた」は習熟度3以上。
- 分野・出題（ぜんぶ／苦手／未学習）・問題数をしぼりこめます。
- 結果は「コピー」して、ノートなどに貼れます。記録は、この端末のブラウザにだけ保存されます。

## データの確認と修正（先生用）
1. タイトル画面の **「✎ データかくにん」** を開く
2. 1つずつ **○確認ずみ / ✎要修正** を付け、直し方をコメントに書く（分野ごとに「ぜんぶ確認ずみ」にもできる）
3. **「要修正・コメントをコピー」** で、まとめて送れる
4. 直接直す場合は、`terms.js` を編集する
   - `t` = 用語、`d` = 説明文、`n` = 考察のポイント（なくてもよい）、`c` = 分野
   - 説明文の中に、用語そのものを書かないでください（「説明→用語」の問題で、答えが見えてしまうため）
   - 正誤問題は `s` = 文、`a` = true/false、`e` = 解説
   - 用語を書き換えると、その用語の記録（覚えた状況）は、リセットされます

確認ずみの状態は、この端末のブラウザにだけ保存されます（`terms.js` を直しても消えません）。

## 調整用定数
`index.html` 冒頭の `const CONFIG = {...}`（問題数の選択肢、出やすさの重み、「覚えた」の基準、音量）。
